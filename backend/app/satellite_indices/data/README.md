# Bundled test area

`test_area.geojson` is a small square (about 4.2 km2, WGS84) used by the offline demo and
by `python -m satellite_indices.reference_check`. It is a convenient fixed test polygon;
check what it covers on a map before using it for the plausibility checks, and replace
it with your own area when you need a specific land cover (vegetation, water, built-up).
